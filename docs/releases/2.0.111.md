# Release Highlights

Aside 2.0.111 improves Context for notes and Canvas boards and brings note-level Todo filtering into the category menu.

## Highlights

- **More useful Context Files:** linked Canvas boards, Excalidraw drawings, PDFs, documents, images, and other attachments appear together, sorted by file type and name. Duplicate references appear once.
- **Canvas context that follows the board:** Files includes notes and attachments referenced by file cards and text cards. URLs includes links from URL cards and text cards, including current unsaved board content.
- **Saved comments always contribute context:** file references and URLs in saved side comments appear alongside references from the current note or Canvas.
- **Clearer Thought Trail:** ordinary Markdown note connections stay in Thought Trail; Canvas boards and drawings, including Excalidraw drawings saved as Markdown, belong in Context Files.
- **Todo in the category filter:** filter a note's comments by Todo alongside Comments, Agent, and Script. The global Todo tab remains available in Aside Index.
- **Simpler Context controls:** Files and URLs are populated automatically. Existing custom sources remain available to use, edit, or remove.

## Upgrade notes

- For manual installation, install or update using the matching `main.js`, `manifest.json`, and `styles.css` in your vault's `.obsidian/plugins/aside/` folder, preserving settings and data, then reload Aside.
- The minimum supported Obsidian version remains 1.12.7.
