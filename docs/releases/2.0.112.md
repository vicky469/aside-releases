# Release Highlights

Aside 2.0.112 fixes missing Markdown tags in Index Tags and adds temporary exclusions for more useful search results.

## Highlights

- **Find tags across your vault:** tagged Markdown notes appear even when they have no Aside comments. Tags from saved comments remain searchable, and files appear only once.
- **Refine matching tags:** use the small × on a tag chip to exclude it from the current results. Counts update, and files matching another included tag stay visible.
- **Easy corrections:** Reset exclusions restores the matches. Starting a new search clears exclusions automatically; Markdown tags stay unchanged.

## Upgrade notes

- Requires Obsidian 1.12.7 or later.
- For manual installation, update `main.js`, `manifest.json`, and `styles.css` together in `.obsidian/plugins/aside/`, preserve settings and data, and reload Obsidian.
- The production build is separated from the integration-test suite so the community directory can verify the release in a clean build environment.
