# Release Highlights

Aside 2.0.113 makes scripts easier to run, improves comment navigation, and introduces a simpler animated Settings header.

## Highlights

- **Run event scripts on demand:** use Run file for the current note or Run all for matching files. Compact rule controls, progress reporting, and protection against automatic reruns make manual execution easier to follow.
- **Choose and clarify script agents:** select the agent from the script card dropdown. When a script update needs clarification, reply to continue the pending task with its context preserved.
- **Start each page with All:** navigating to a page resets its sidebar to All. The sidebar shows its file beneath search, and file context appears beside a pinned sidebar when needed.
- **Comment on Markdown images:** attach comments directly to images in Markdown notes and return to the image from its comment.
- **Control Context scope:** a compact switch selects file links alone or includes saved comments. Chinese prose following comment links stays outside the URL.
- **More reliable parallel agent work:** additional requests queue within the available worker capacity, and local development reloads wait for active work and saves to finish.
- **A lighter Settings illustration:** a minimal bunny, three colored orbiting dots, and one anchored conversation show the comment-to-reply flow. The callout draws from the document and disappears between cycles. Pause and reduced-motion support are included.

## Upgrade notes

- Requires Obsidian 1.12.7 or later.
- For manual installation, update `main.js`, `manifest.json`, and `styles.css` together in `.obsidian/plugins/aside/`, preserve settings and data, and reload Obsidian.
